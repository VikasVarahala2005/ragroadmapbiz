The Tree Diagram of RAG

Hierarchical Breakdown of Retrieval-Augmented Generation Components


RAG Architecture Tree
├── 1. Data Ingestion & Indexing
│   ├── Document Loaders (PyPDF, Text, Web)
│   ├── Text Splitters (RecursiveCharacterTextSplitter)
│   └── Vector Store (Chroma, Pinecone, FAISS)
├── 2. Retrieval Phase
│   ├── Query Transformation (Multi-Query, Hypothetical Document Embeddings)

└── 3. Generation Phase
    ├── Context Formatting
    ├── Prompt Templates
    └── LLM Generation (OpenAI, HuggingFace)
